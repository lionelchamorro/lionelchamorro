# Hi, I'm Lionel 👋

**Mathematician · AI/ML Engineer · Managing Partner at [Collective AI](https://collectiveai.io)**

I build AI systems that move from research to production, with a current focus on **agentic software engineering, generative AI, voice AI, local LLMs, and applied machine learning**.

I also enjoy working at the intersection of **mathematics, deep learning, developer tooling, and chess**.

<br clear="right"/>

## What I'm working on

- 🤖 **Agentic engineering** — workflows, skills, governance, and tooling for coding agents.
- 🧠 **Applied AI & ML** — production systems, forecasting, deep learning, and generative AI.
- 🗣️ **Voice AI** — real-time assistants where speech, reasoning, and actions stay synchronized.
- 🖥️ **Local LLMs** — practical ways to run capable models on constrained hardware.
- 📚 **Math & Deep Learning** — educational material connecting mathematical foundations with modern architectures.
